Icon Reference Guide

A complete reference guide for all toolbar buttons, status indicators, and actions in the app.
Toolbar (Top)
Add Link — Add a new HTTP or stream download by URL
Torrent — Import a .torrent file from disk or paste a magnet link
Options — Open settings (Storage, Startup, DNS, Engine updates)
Help — Submenu for Icon Guide and About modal
Exit — Close and terminate the application completely
Speed Column — Engine Indicator
Double bolt (gold) — Multi-Thread HTTP download (16 parallel connections)
Single bolt (green) — Single-Thread HTTP download
Chain link (sky blue) — HLS Video Stream download (multi-segment ts/aac)
Torrent icon (amber) — BitTorrent P2P download (WebTorrent engine)
Download Actions (Action Column)
Pause — Pause an active download
Resume — Resume a paused download
Retry — Restart a failed or zero-peer download
Cancel — Stop and abort an ongoing download
Open Folder — Reveal download directory in system file explorer
Open File — Open the completed file with default OS application
Delete — Prompt confirmation and remove record from history
Status Colors & Meaning
Yellow — Downloading, Connecting, In Progress, or Paused
Green — Completed successfully
Red — Error, Failed, Cancelled, Duplicate, or No Peer
Gray — Idle or not applicable
Table Sorting (Click Header)
▲ Up arrow — Sorted ascending (A→Z, 0→100%, oldest first)
▼ Down arrow — Sorted descending (Z→A, 100%→0, newest first)
↔ Column Resizing — Drag the border between headers to resize column widths
Peers Column
15 Yellow number — Active connected peers/seeders (BitTorrent downloads)
- Dash (gray) — Not applicable (HTTP & HLS downloads)
Status Bar & Terminal (Bottom Bar)
CPU — Application CPU usage percentage
RAM — Application memory usage in Megabytes (MB)
↓ Green arrow — Aggregate live download speed
↑ Yellow arrow — Aggregate live upload speed (BitTorrent)
Terminal Toggle — Open/close the integrated extension log terminal
